# 中英文術語表

[返回目錄](../README.md)

依英文排序；HTML 搜尋可輸入中文或英文，中文對照也可用瀏覽器搜尋。

<a id="term-alias"></a>

## Alias（別名）

指向命令的名稱捷徑，不能直接附帶固定參數。 [對應章節](../../docs/chapters/07-commands-aliases.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Command_Precedence.md)。

<a id="term-argument"></a>

## Argument（引數）

實際傳入參數的值，不等同參數名稱。 [對應章節](../../docs/chapters/06-help-system.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_CommonParameters.md)。

<a id="term-array"></a>

## Array（陣列）

按索引存放多項資料，索引由零開始。 [對應章節](../../docs/chapters/12-collections.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Arrays.md)。

<a id="term-bom"></a>

## BOM（位元組順序記號）

檔案開頭的 Unicode 編碼提示，可協助舊版辨識中文。 [對應章節](../../docs/chapters/03-installation.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/install/PowerShell-Support-Lifecycle.md)。

<a id="term-boolean"></a>

## Boolean（布林值）

真或假的判斷值，與文字 True/False 不同。 [對應章節](../../docs/chapters/11-variables-types.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Variables.md)。

<a id="term-breakpoint"></a>

## Breakpoint（中斷點）

讓偵錯器在指定行、變數或命令暫停以觀察狀態。 [對應章節](../../docs/chapters/20-debugging-logging.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Debuggers.md)。

<a id="term-bypropertyname"></a>

## ByPropertyName（按屬性名稱繫結）

依輸入物件屬性名稱配給參數，型別也要符合。 [對應章節](../../docs/chapters/09-pipeline.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Pipelines.md)。

<a id="term-byvalue"></a>

## ByValue（按值繫結）

依整個管線輸入物件的型別配給參數。 [對應章節](../../docs/chapters/09-pipeline.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Pipelines.md)。

<a id="term-cmdlet"></a>

## Cmdlet（PowerShell 命令）

參與 PowerShell 管線與參數機制的命令；不要把所有外部程式都叫 Cmdlet。 [對應章節](../../docs/chapters/07-commands-aliases.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Command_Precedence.md)。

<a id="term-debugging"></a>

## Debugging（偵錯）

在可重現案例中觀察執行脈絡與資料以找出問題。 [對應章節](../../docs/chapters/20-debugging-logging.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Debuggers.md)。

<a id="term-encoding"></a>

## Encoding（編碼）

文字與位元組之間的表示方式，與換行格式不同。 [對應章節](../../docs/chapters/03-installation.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/install/PowerShell-Support-Lifecycle.md)。

<a id="term-error-handling"></a>

## Error Handling（錯誤處理）

辨認與傳播失敗、清理資源，避免把失敗當成功。 [對應章節](../../docs/chapters/19-error-handling.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Try_Catch_Finally.md)。

<a id="term-exception"></a>

## Exception（例外）

描述異常執行狀態的物件，可由適當錯誤處理捕捉。 [對應章節](../../docs/chapters/19-error-handling.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Try_Catch_Finally.md)。

<a id="term-execution-policy"></a>

## Execution Policy（執行原則）

協助避免意外執行指令碼的機制，不是完整安全邊界。 [對應章節](../../docs/chapters/03-installation.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/install/PowerShell-Support-Lifecycle.md)。

<a id="term-function"></a>

## Function（函式）

具名字、輸入與輸出的可重用程式區塊。 [對應章節](../../docs/chapters/16-functions.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Functions.md)。

<a id="term-hashtable"></a>

## Hashtable（雜湊表）

以鍵值對查找資料，一般不保證列舉順序。 [對應章節](../../docs/chapters/12-collections.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Arrays.md)。

<a id="term-lts"></a>

## LTS（長期維護版本）

有較長維護期限的發行系列，仍需更新安全修補。 [對應章節](../../docs/chapters/02-powershell-versions.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/install/PowerShell-Support-Lifecycle.md)。

<a id="term-logging"></a>

## Logging（記錄日誌）

留下可追蹤的事件與結果，需去除秘密與控制保存期限。 [對應章節](../../docs/chapters/20-debugging-logging.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Debuggers.md)。

<a id="term-method"></a>

## Method（方法）

物件提供的操作，呼叫時可能有副作用。 [對應章節](../../docs/chapters/08-objects.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Objects.md)。

<a id="term-module"></a>

## Module（模組）

封裝函式、Cmdlet、提供者及資源的可重用單位。 [對應章節](../../docs/chapters/18-modules.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Modules.md)。

<a id="term-object"></a>

## Object（物件）

以型別、屬性與方法表達資料及可用操作。 [對應章節](../../docs/chapters/08-objects.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Objects.md)。

<a id="term-parameter"></a>

## Parameter（參數）

命令輸入介面的欄位，例如 LiteralPath。 [對應章節](../../docs/chapters/06-help-system.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_CommonParameters.md)。

<a id="term-parameter-binding"></a>

## Parameter Binding（參數繫結）

將命令列引數或管線資料配給接收參數的過程。 [對應章節](../../docs/chapters/09-pipeline.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Pipelines.md)。

<a id="term-parameter-set"></a>

## Parameter Set（參數組合）

定義哪些參數可一起呼叫及各自必要性。 [對應章節](../../docs/chapters/06-help-system.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_CommonParameters.md)。

<a id="term-pipeline"></a>

## Pipeline（管線）

把前段成功輸出送到後段處理；接收參數必須支援該輸入。 [對應章節](../../docs/chapters/09-pipeline.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Pipelines.md)。

<a id="term-profile"></a>

## Profile（設定檔）

啟動時載入的 PowerShell 指令碼，依使用者與主控程式範圍區分。 [對應章節](../../docs/chapters/04-terminal-editor.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/learn/ps101/01-getting-started.md)。

<a id="term-property"></a>

## Property（屬性）

物件的一項資料，例如 Name；畫面不一定顯示全部屬性。 [對應章節](../../docs/chapters/08-objects.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Objects.md)。

<a id="term-provider"></a>

## Provider（提供者）

讓檔案、登錄等資料以一致巡覽方式呈現的機制。 [對應章節](../../docs/chapters/05-basic-navigation.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/learn/ps101/01-getting-started.md)。

<a id="term-scope"></a>

## Scope（作用域）

變數與函式可見及生效的範圍。 [對應章節](../../docs/chapters/16-functions.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Functions.md)。

<a id="term-script"></a>

## Script（指令碼）

保存一或多個命令的文字檔，可重複執行與版本管理。 [對應章節](../../docs/chapters/15-scripts.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Scripts.md)。

<a id="term-session"></a>

## Session（工作階段）

一次執行脈絡，包含載入模組、變數與設定。 [對應章節](../../docs/chapters/04-terminal-editor.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/learn/ps101/01-getting-started.md)。

<a id="term-shell"></a>

## Shell（命令殼層）

理解使用者命令並啟動執行的環境。 [對應章節](../../docs/chapters/01-introduction.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/overview.md)。

<a id="term-shouldprocess"></a>

## ShouldProcess（變更前確認機制）

讓變更命令配合 WhatIf 與 Confirm，副作用須放在受保護分支。 [對應章節](../../docs/chapters/17-advanced-functions.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Functions_Advanced.md)。

<a id="term-splatting"></a>

## Splatting（參數展開）

用字典或陣列整理呼叫引數，減少長單行命令。 [對應章節](../../docs/chapters/16-functions.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Functions.md)。

<a id="term-string"></a>

## String（字串）

文字資料；引號與編碼規則會影響使用方式。 [對應章節](../../docs/chapters/11-variables-types.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Variables.md)。

<a id="term-switch-parameter"></a>

## Switch Parameter（切換參數）

通常以旗標啟用的參數，不是額外傳入文字 True。 [對應章節](../../docs/chapters/06-help-system.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_CommonParameters.md)。

<a id="term-terminal"></a>

## Terminal（終端機）

顯示文字並接收輸入的介面，不等同殼層版本。 [對應章節](../../docs/chapters/04-terminal-editor.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/docs-conceptual/learn/ps101/01-getting-started.md)。

<a id="term-transcript"></a>

## Transcript（工作階段逐字紀錄）

保存互動內容，可能含敏感資訊，分享前要檢查。 [對應章節](../../docs/chapters/20-debugging-logging.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Debuggers.md)。

<a id="term-type"></a>

## Type（型別）

定義資料種類與可用操作的規則。 [對應章節](../../docs/chapters/11-variables-types.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Variables.md)。

<a id="term-variable"></a>

## Variable（變數）

保存值的具名位置，以美元符號開頭。 [對應章節](../../docs/chapters/11-variables-types.md)；[官方來源](https://github.com/MicrosoftDocs/PowerShell-Docs/blob/a3de8f22552170e70852470d46cd52cd9ca471ec/reference/7.6/Microsoft.PowerShell.Core/About/about_Variables.md)。
