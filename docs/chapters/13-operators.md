# 第 13 章：運算子與運算式

[返回目錄](../README.md)

## 學習目標

讀懂比較、包含、邏輯與算術運算，分辨純量與集合比較的輸出，避免把語言運算子當成 Cmdlet 參數。

## 算術與字串

Operator（運算子）組合資料，Expression（運算式）算出結果。`+ - * / %` 分別是加、減、乘、除、餘數，但型別會改變語意。`'a' + 'b'` 串接文字，`'a' * 3` 重複字串；不是所有加號都在做數學。

```powershell
(2 + 3) * 4
10 % 3
'a' + 'b'
```

結果為 20、1、ab。括號清楚表達先後順序，比讓讀者死記優先序更容易維護。

## 純量比較與集合比較

```powershell
3 -gt 2
1, 2, 3 -gt 1
1, 2, 3 -contains 2
2 -in 1, 2, 3
```

第一行 True；第二行回傳符合條件的 2 與 3，不是單一布林值。`-contains` 與 `-in` 則做成員關係判斷並回傳布林值，左右方向相反。不要把「包含子字串」與「集合包含一項」混為一談：字串內容可用 `-like`、`-match` 或字串方法。

## 邏輯與空值

```powershell
$age = 20
$hasPermission = $true
($age -ge 18) -and $hasPermission
-not $hasPermission
$null -eq $missingLearningValue
```

本範例最後一行示範未定義變數在一般模式下的空值比較；嚴格模式下可能改為錯誤，因此正式腳本應先初始化，不把這行當成檢查任意變數的通用解法。把 `$null` 放比較左側，可避免右側集合逐項比較帶來意外形狀。

`-and`、`-or` 可短路求值，但不可把副作用藏在條件式裡，否則有些分支根本不會執行。`-not` 反轉布林判斷。

## 型別、格式與版本差異

```powershell
42 -is [int]
'{0}: {1}' -f '數量', 3
```

`-is` 檢查型別，`-f` 依索引格式化字串。PowerShell 7 新增 `? :` 三元運算、`??` 空值合併與 `&&`／`||` 管線鏈結等能力；它們不適用 5.1。管線鏈結看前段成功狀態，不等同於一般比較結果的布林運算；開始學習時先用清楚的 if。

## 常見錯誤、安全與最佳實踐

純量與集合比較回傳形狀不同，是「有時 True、有時一串資料」的常見原因。條件要表示有無成員時，使用明確的 contains/in；要篩選資料時，使用 Where-Object 或理解集合比較結果。不要把 `-eq` 改成其他語言的 `==`。

本章運算僅在記憶體，不修改系統；字串格式化仍應避免輸出敏感資料。數字、空集合、空字串與 null 都要各測一種。

## 速查表

| 運算子 | 中文用途 | 結果特徵 |
|---|---|---|
| `-eq/-ne` | 相等／不等 | 集合左值可能回傳子集合 |
| `-contains` | 集合含某值 | 布林值 |
| `-in` | 某值在集合內 | 布林值 |
| `-and/-or/-not` | 且／或／非 | 條件邏輯 |
| `-is` | 型別判斷 | 布林值 |
| `-f` | 格式化字串 | 字串 |

8. `-contains`，集合放左邊。

9. 被查值放左邊，集合放右邊，例如 `2 -in 1,2,3`。

10. 布林值。

11. 不是，它檢查集合成員；子字串需用適合的文字方法或模式。
